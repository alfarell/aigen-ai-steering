# Handoff prompt

Prepare a self-contained handoff for the current Aigen task.

Include:

- objective, scope, and active specification path;
- repository/branch/status for each affected repository;
- pre-existing changes that must be preserved;
- verified current behavior and decisions;
- files/symbols/interfaces/data changed;
- completed and remaining tasks;
- tests/commands with exact results;
- failures, blockers, risks, and unverified behavior;
- deploy/migration order, feature flags, monitoring, and rollback;
- affected `aigen-ai/` files that were updated or still need refresh.

Do not include secrets, environment values, full tokens, or production data.
